---
description: "Check new vulnerability advisories against portfolio dependencies and route affected repositories into findings."
---

Run the advisory-driven dependency lane using .claude/skills/dependency-watch/SKILL.md. Refresh feeds with `traust feeds fetch`, select the requested advisory or generate the fleet worklist with `traust impact sweep`, and run each `impact_argv` as an argument vector. Current recorded SBOMs supply blast radius. `traust impact analyze` records per-package/version assessments and files only `affected` findings through Core intake, with advisory-declared severity and idempotent repository/advisory/package identity; it never writes a baseline. Report commit/analysis counts, all classifications, affected finding IDs and sweep coverage gaps. `--dry-run` means stage and report the worklist without invoking analyze; `--include-likely` is retired, not forwarded. In air-gapped runs pass each exported OSV record with `--advisory-file`; include every alias export. Export retained advisory results with `traust impact export <advisory> --out <path>` for verification consumers.
